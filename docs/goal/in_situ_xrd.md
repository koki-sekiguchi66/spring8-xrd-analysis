# 準安定オーステナイト鋼 In-situ XRD 全自動解析システム 実装計画書

## 1. プロジェクト概要・目的

### 1.1 背景と課題
現在、準安定オーステナイト鋼のIn-situ X線回折（XRD）測定データの解析は以下の手作業を介した多段階フローで行われており、多大な時間的コストとヒューマンエラーのリスクを抱えています。
1. Spyder上で `.tth` ファイルを `tth/` ディレクトリへ、その他を `others/` ディレクトリへ振り分けるスクリプトを手動実行。
2. `tth/` ディレクトリ内の全ファイルに対してバックグラウンド除去スクリプトを実行し、`bcg_removed_arpls/` にCSVを出力。
3. バックグラウンド除去後のCSVをOriginソフトウェアに読み込み、各相（オーステナイト $\gamma$ 相・マルテンサイト $\alpha'$ 相）の各面指数に対して手動でVoigtフィッティングを実施し、得られた中心角（`xc`）・面積強度（`A`）・半値幅（`wG`, `wL`）等を `（試料名）_initial.xlsx` に手動でコピー＆ペースト。
4. ピークの重畳有無に応じて、単一ピーク用スクリプトまたはMultiピーク用スクリプト（2ピーク強度比固定、3ピークリュダース変形後、汎用Multiピーク）のパスや初期設定を書き換えて個別に実行し、`output.xlsx` へ出力。

### 1.2 システム構築の目的
上記のワークフローを刷新し、**「解析したい `.tth` ファイル群が入った個別の試料ディレクトリを選択するだけ」で、仕分け・バックグラウンド除去・初期値フィッティング・採用ピーク選択・全ファイル連続解析・Excel出力までを一気通貫で完結させるローカルアプリケーション**を構築します。

* **動作環境**: Windows 11 ローカルPC環境（完全オフライン動作、外部サーバーへのデータ送信ゼロ）。
* **解析対象材料**: 準安定オーステナイト鋼（面心立方格子 $\gamma$-FCC オーステナイト相 および 体心立方/正方格子 $\alpha'$-BCC マルテンサイト相の二相系）に最適化。
* **計算精度の担保**: 初期値算出および連続フィッティングはOriginソフトウェアのVoigt関数定義と数学的に完全一致させ、既存スクリプトの物理的制約ロジックを継承しつつ潜在バグをすべて修正。

## 3. 解析パイプライン・アルゴリズム詳細設計

### 3.1 Stage 1: ディレクトリ構造の自動認識とファイル仕分け (`separator.py`)
ユーザーが解析対象の個別ディレクトリ（例：`D:\Tsujilab\SP8\0.8C90CR`）を選択した際、以下のルールで自動仕分けを行います。
1. 選択されたディレクトリ直下に既に `tth/` フォルダが存在し、その中に `.tth` ファイルが入っている場合は仕分け済みと判定してスキップします（冪等性の確保）。
2. 直下に `.tth` ファイルが混在している場合、`tth/` および `others/` サブディレクトリを自動生成し、拡張子 `.tth`（大文字・小文字不問）を `tth/` へ、その他のファイルを `others/` へ移動します。
3. 既存スクリプト（`separate tth_ver2.0.py`）にあった「ファイル数50未満のフォルダをスキップする制限（`if len(os.listdir(...)) < 50: continue`）」は、少数ファイルの試験データでも確実に動作するよう撤廃します。

### 3.2 Stage 2: スパイク除去＋Rubberband＋PCHIPバックグラウンド除去 (`bg_remover.py`)
`tth/` 内のすべての `.tth` ファイルに対し、既存の `remove_bcgs_arpls+rubberband_ver2.py` のアルゴリズムを忠実に実行し、`bcg_removed_arpls/` フォルダへ `{元ファイル名}bcg.csv` として保存します。
1. **データ切り出し**: 回折角 $2\theta > \text{th\_min}$（デフォルト $10.2^\circ$、UIから変更可能）のデータ点 $(x_{\text{sub}}, y_{\text{sub}})$ を抽出。
2. **スパイクノイズ除去**: 隣接点間の差分絶対値の中央値 $\text{median}(|\Delta y|)$ を基準とし、前後両方の点から $\text{threshold\_factor} \times \text{median}(|\Delta y|)$（デフォルト係数 `5`）以上落ち込んでいる下向きスパイク点を前後点の平均値で補間。
3. **アンカーポイント抽出**: `scipy.signal.find_peaks(-y_despiked, distance=100)` により局所的な谷（極小点）を検出し、両端点（インデックス `0` と `len-1`）を加えた候補点周辺（窓幅 `valley_avg_window = 11`）の平均座標 $(x_{\text{anchors}}, y_{\text{anchors}})$ を算出。
4. **Rubberbandフィルタ（下側凸包）**: 現在のアンカー点から見て、後方にある点の中で最も傾き $\Delta y / \Delta x$ が小さくなる点を順次繋ぎ、ピークの裾野を横切らない下側包絡線アンカー $(x_{\text{mono}}, y_{\text{mono}})$ を抽出。
5. **PCHIP補間とarPLSフォールバック**: アンカーが2点以上存在する場合は `scipy.interpolate.PchipInterpolator` で滑らかなベースライン曲線を生成し、アンカー不足時は `pybaselines.whittaker.arpls(lam=1e7)` に自動フォールバックしてベースラインを差し引きます。

### 3.3 Stage 3: Origin完全互換Voigt初期値探索＆二相ピーク同定 (`initial_guesser.py`)

#### (1) Originソフトウェアと完全一致するVoigt関数定義
OriginのPeak Analyzerが用いるVoigt関数は以下の数式で定義されます。

$$y(x) = y_0 + A \frac{2\ln 2}{\pi^{3/2}} \frac{w_L}{w_G^2} \int_{-\infty}^{\infty} \frac{e^{-t^2}}{\left(\sqrt{\ln 2}\frac{w_L}{w_G}\right)^2 + \left(\sqrt{4\ln 2}\frac{x - x_c}{w_G} - t\right)^2} dt = y_0 + A \cdot \frac{\text{Re}\left[w(z)\right]}{\sigma\sqrt{2\pi}}, \quad z = \frac{(x - x_c) + i\gamma}{\sigma\sqrt{2}}$$

ここで、$w(z) = e^{-z^2}\text{erfc}(-iz)$ はFaddeeva関数（`scipy.special.wofz`）であり、Originの出力パラメータ（中心角 $x_c$、面積強度 $A$、ガウス半値幅 $w_G$、ローレンツ半値幅 $w_L$、合成半値幅 $\text{FWHM}$）と `lmfit.models.VoigtModel` の内部パラメータ（`center`, `amplitude`, `sigma`, `gamma`）は以下の厳密な関係式で相互変換されます。

* **ガウス幅の変換**:
  $$\sigma = \frac{w_G}{2\sqrt{2\ln 2}}, \quad w_G = 2\sigma\sqrt{2\ln 2}$$
* **ローレンツ幅の変換**:
  $$\gamma = \frac{w_L}{2}, \quad w_L = 2\gamma$$
* **FWHM（半値全幅：Olivero-Longbothum近似式）**:
  $$\text{FWHM} = 0.5346 w_L + \sqrt{0.2166 w_L^2 + w_G^2}$$

> **【実装上の重要仕様】**
> `lmfit.models.VoigtModel` はデフォルトで `gamma` パラメータに `expr='sigma'` という拘束式が設定されています。Originと同一の計算結果を得るため、パラメータ初期化時に必ず `pars[f'v{k}_gamma'].set(value=..., min=1e-5, vary=True, expr=None)` を設定し、$w_G$ と $w_L$ を独立にLevenberg-Marquardt法（`method='leastsq'`）で最適化します。また、Originと同様に局所ベースライン定数 $y_0$（`ConstantModel`）を含めてフィットするか、$y_0=0$ に固定するかをUIで選択可能にします。

#### (2) 複数ファイルの自動選出／手動指定（変形初期 $\gamma$ 単相 ＋ 変形後期 $\gamma+\alpha'$ 二相）
準安定オーステナイト鋼では、変形初期にはオーステナイト（$\gamma$-FCC）のみが存在し、変形が進むと加工誘起マルテンサイト変態（DIMT）によりマルテンサイト（$\alpha'$-BCC）が出現します。両相の正確な初期値を得るため、以下の2つのモードを提供します。

* **自動選出モード（Auto Mode）**:
  全 `*bcg.csv` ファイルをスキャンし、以下の2ファイル（必要に応じて中間ファイルを含む複数ファイル）を自動選出します。
  1. **変形初期代表ファイル（$\gamma$ 相基準、例：`num = 50`）**: 先頭5〜10%の領域から、`fcc111` 主ピーク強度が高く、かつ $\alpha'$ 相出現領域（`bcc211` 付近の $19.8^\circ \sim 20.3^\circ$）の積分強度がノイズレベル以下のファイルを選出。
  2. **変形後期代表ファイル（$\gamma+\alpha'$ 二相基準、例：`num = 900`）**: 後半80〜95%の領域から、$\alpha'$ 相（`bcc110` および `bcc211`）の積分強度が十分に発達し、プロファイルにスパイク異常がないファイルを選出。
* **手動指定モード（Manual Mode）**:
  ユーザーがUI上のスライダーまたは数値入力で任意の `num` 値（例：`50`, `180`, `900` など）を1つまたは複数指定し、指定されたファイルに対して初期フィッティングを実行します。

#### (3) 準安定オーステナイト鋼に特化した面指数自動同定と「単一／Multiペア」分類
選出された各ファイルに対し、結晶学的な消滅則とブラッグの法則に基づいて以下の9つの面指数（$\gamma$ 相5本、$\alpha'$ 相4本）を自動探索します。

$$\sin\theta_{hkl} = \frac{\lambda}{2a}\sqrt{h^2 + k^2 + l^2}$$

1. **基準ピークからの角度予測**:
   $11^\circ \sim 12^\circ$ 付近の最大ピークを `fcc111` ($h^2+k^2+l^2=3$) または `bcc110` ($h^2+k^2+l^2=2$) として検出し、オーステナイトとマルテンサイトの格子定数比（$a_\gamma / a_{\alpha'} \approx 1.251$）から全候補ピークの理論 $2\theta$ 位置を自動算出します。
2. **単一ピーク候補とMultiピークペア候補の自動グループ化**:
   実データ（`Seki_age_2_0050bcg.csv` および `0900bcg.csv`）のピーク配置に基づき、以下のように単一ピークと重畳ペア（Multiピーク用）を分類してユーザーに提示します。

| 候補グループID | 対象ピーク（面指数） | 含まれる相 | 推奨初期値取得元 | 適用する連続解析エンジン |
| :--- | :--- | :--- | :--- | :--- |
| **候補① (ペア)** | **`fcc111` + `bcc110`**<br>（または3ピーク `+ bcc1102`） | $\gamma + \alpha'$（重畳） | 変形後期ファイル（`bcc110`）＋<br>変形初期/後期ファイル（`fcc111`） | **Multiピーク解析**<br>（2ピーク比探索 / 3ピークLuders / 汎用Multi） |
| **候補② (単一)** | **`fcc200`** | $\gamma$ 単一 | 変形初期ファイル（高強度・高S/N） | **単一ピーク解析** (`1Peak`) |
| **候補③ (単一)** | **`bcc200`** | $\alpha'$ 単一 | 変形後期ファイル（※微弱時は非推奨表示） | **単一ピーク解析** (`1Peak`) |
| **候補④ (単一/Multi)** | **`fcc220`** | $\gamma$ 単一 | 変形初期ファイル | **単一ピーク解析** (`1Peak`) または広域Multi |
| **候補⑤ (単一/Multi)** | **`bcc211`** | $\alpha'$ 単一 | 変形後期ファイル | **単一ピーク解析** (`1Peak`) または広域Multi |
| **候補⑥ (単一/Multi)** | **`fcc311`** | $\gamma$ 単一 | 変形初期ファイル | **単一ピーク解析** (`1Peak`) または広域Multi |
| **候補⑦ (ペア)** | **`fcc222` + `bcc220`**<br>（または $18^\circ \sim 24^\circ$ 一括Multi） | $\gamma + \alpha'$（重畳） | 変形後期ファイル（2相ペア同時フィット） | **Multiピーク解析** (`MultiPeaks`) |

#### (4) `（試料名）_initial.xlsx` の自動統合生成
ユーザーがUI上で目視確認し、「どのファイルのどのピーク初期値を採用するか」にチェックを入れた後、既存スクリプトの `import_initial_values()` がそのまま読み込める2段ヘッダー構造（1行目：ピーク名、2行目：`No`, `y0`, `xc`, `A`, `wG`, `wL`）の `（試料名）_initial.xlsx` をバックグラウンドで自動生成します。

### 4.1 原田スクリプト準拠への是正（2026-11 監査）

解析フロー全体の整合（2026-11 統合時）:

| 項目 | 内容 |
| :--- | :--- |
| 初期値ファイル | 原田さんの手順どおり `_initial.xlsx` を初期値の正とする。Step 2 は群ごと・代表フレームごとに 1 ブロックを書き出し（2 ピーク群は R 粗探索用に 5 行）、Step 3 は入室時と実行直前に読み直す（Excel / Origin で編集した値が使われる）。ブロックの選択: 2PeaksRatio = 変態開始以前で最も遅いフレーム、3PeaksLuders = 変態開始以後で最も遅いフレーム、その他 = Step 2 で選んだフレーム。Lüders 群の追加時は変態後フレームの 3 ピーク Origin fit をブロックとして追記（既存ブロックは手編集を優先して上書きしない）。読めない場合は実行を中止 |
| Step 2 のベースライン | Origin Peak Analyzer と同じ選択肢: なし (Y=0) / 定数 y0（Voigt の y0 をピークと同時に fit）/ 端点重み付け（窓両端の指定 % の点を隣接平均で平滑化し線形補間して差し引き。平滑化窓は選択点の 6%）/ 直線（両端点を結ぶ直線を差し引き、または切片・傾きをピークと同時に fit）。既定は定数 y0（Origin の Voigt 関数の既定で、原田さんの初期値も y0≠0）。窓端から作るベースラインは幅の広い α' の裾を削る（模擬データで bcc211 −14〜−21%）ため任意。Step 3 の連続解析結果は初期値のベースライン選択にほぼ依存しない（模擬データ、変態後で中央値差 0%、最大 4%） |
| 冷間圧延材フロー | Step 3 で fcc111+bcc110 を 2PeaksRatio にすると初期値を変態前フレームに切替。「変態後の 3PeaksLuders 群を追加」で同じ反射の Lüders 群（num ≥ 変態開始）を作成し、実行時に 2PeaksRatio の best_R を R として引き継ぐ（2PeaksRatio → 3PeaksLuders の順で実行）。2 ピークの初期値からは v2 = R·v1、残りを v3（新生 α'）として 3 成分初期値を生成 |
| 既存 α' の扱い | 2PeaksRatio / 3PeaksLuders 群があるセッションでは、どの群でも変態前 α' を 0 とみなさない（既存マルテンサイトあり） |
| Step 4 再フィット | 既定は「エンジン準拠」: Step 3 と同じエンジン・拘束・残差定義で、解析方向の直前フレーム（逆向き区間は num+1、前向き区間は num−1）を初期値に 1 フレームだけ再計算。2PeaksRatio は best_R を固定。再計算後も残差基準を超えるものは要確認のまま残す。従来の自由 Origin Voigt は任意 |
| 定数背景 y0（任意・原田法外） | 窓内に y0 を加えて fit（前フレームの y0 を引継ぎ、上限は窓端の強度）。背景除去後に残留背景がある場合、y0 なしでは幅の広い α' が残留背景を吸収して面積を過大評価する（模擬データで bcc211 +22% → −2%、f 誤差 +0.037 → +0.004）。弱いピーク（bcc321）では y0 と裾が分離できず過小評価に転じるため既定は無効 |
| 解析範囲 | Step 5 で num の上限を指定可能。全フィット強度の持続的な急落（直前 15 フレーム中央値の 50% 未満が 6 フレーム継続）を破断として検出し、除外を提案 |

## 5. UI / UX 画面設計および操作ワークフロー

初めて操作するユーザーでも迷わず直感的に解析を完了できるよう、画面上部にプログレスステップを備えた **4ステップ・ウィザード形式** のモダンUI（ダーク／ライトテーマ切替対応）を設計します。

### Step 1: フォルダ選択 ＆ 自動前処理（仕分け・バックグラウンド除去）画面
* **操作**: 画面中央のドロップゾーンまたは「フォルダを選択」ボタンから、`.tth` ファイルが入ったディレクトリを選択します。
* **自動処理と視覚フィードバック**:
  * 即座に `tth/` と `others/` への仕分けが実行され、続いて全ファイルのバックグラウンド除去（スパイク除去＋Rubberband＋PCHIP）が並列処理で進行します。
  * 画面右側のPlotlyグラフにて、任意のファイル番号の「Rawデータ」「スパイク除去後」「Rubberbandアンカー点（オレンジ丸）」「PCHIPベースライン（緑破線）」「BG除去後データ（赤実線）」を重ねてプレビュー確認でき、必要に応じて `th_min`（デフォルト $10.2^\circ$）等をスライダーで調整して再実行できます。

### Step 2: 初期値マルチファイル探索 ＆ 採用ピーク目視選択画面（中核機能）
* **ファイル選択モード切替**:
  * **「自動選出モード」**: システムが自動選出した「変形初期ファイル（例：`num = 50`、$\gamma$ 単相）」と「変形後期ファイル（例：`num = 900`、$\gamma+\alpha'$ 二相）」の2つのタブが自動生成されます。
  * **「手動指定モード」**: ユーザーが任意の `num` 値（例：`50`, `200`, `900`）を入力またはスライダーで選択し、解析リストに追加します。
* **検出相・面指数のグラフ目視確認と採用ピーク選択**:
  * **上部メイングラフ**: 全体回折プロファイル上に、検出されたオーステナイト相（$\gamma$: 青系バッジ `fcc111`, `fcc200`, `fcc220`, `fcc311`, `fcc222`）とマルテンサイト相（$\alpha'$: 赤/橙系バッジ `bcc110`, `bcc200`, `bcc211`, `bcc220`）のピーク位置がマーカー表示されます。
  * **下部拡大カード＆チェックリスト**:
    * 単一ピーク候補（`fcc200` 等）および二相が重なるMultiピークペア候補（`fcc111 + bcc110` ペア、`fcc222 + bcc220` ペア等）がカード形式で一覧表示されます。
    * 各カードには「実測点」「Origin互換Voigtフィット曲線」「各成分の分離波形」「残差」および算出された初期値（`No`, `xc`, `A`, `wG`, `wL`, `FWHM`, 決定係数 $R^2$）が表示されます。
    * ユーザーは各ピーク・ペアについて**「どの `num` ファイルの初期値を採用するか（例：`fcc200` は `num=50` を採用、`fcc111+bcc110` ペアは `num=900` を採用）」**をラジオボタンで選び、本解析にかける対象にチェックを入れます。
    * グラフ上でピーク位置やフィッティング範囲（`fitting_range_min` / `max`）をマウスドラッグで微調整すると、リアルタイムでVoigtフィットが再計算されます。

### Step 3: 全ファイル連続解析（バッチフィッティング）＆ リアルタイム監視画面
* **解析条件プリセット＆詳細パラメータ設定**:
  * チェックされた各ピーク／ペアに対し、連続解析アルゴリズム（①単一ピーク、②2ピーク強度比 $R$ 探索、③3ピークリュダース後、④汎用Multiピーク）が自動割り当てされます（ドロップダウンで変更可能）。
  * 初心者向けにはデフォルトの拘束条件（`default_fit_limits`）をそのまま適用し、熟練者向けにはアコーディオンメニュー（Advanced Settings）から `DIMT_onset_num`、`residual_limit`、`max_attempts`、各ピークの `center_offset` / `amplitude_factor` / `sigma_factor` / `gamma_factor` を直感的なフォームで編集可能にします。
* **リアルタイム進捗モニター**:
  * 「全ファイル解析スタート」を押すと、各ピークの初期値ファイル（`target_index`）から逆向き（$\rightarrow 0$）および順向き（$\rightarrow \text{final}$）に連続フィッティングが実行されます。
  * WebSocket通信により、現在処理中の波形フィット状況と、`num` に対する **「回折角 $2\theta$ 推移」「面積強度 $I$ 推移」「半値幅 $\text{FWHM} / w_G / w_L$ 推移」** の散布図がリアルタイムでプロットされていきます。

### Step 4: 結果検証・外れ値リペア ＆ Excel出力画面
* **インタラクティブ外れ値検証**:
  * 推移グラフ（$2\theta$, $I$, $\text{FWHM}$）上の任意の点（特に残差が大きかったファイル番号は黄色/赤色でハイライト表示）をクリックすると、そのファイル番号のフィッティング波形と成分分離グラフが即座にポップアップ表示されます。
  * 万が一フィッティングが局所解に陥っているファイルがあれば、そのファイルだけ初期値を微調整して単発再フィット・上書き保存が可能です。
* **ワンクリックExcel出力**:
  * `（試料名）output.xlsx` に、選択されたすべての単一ピークおよびMultiピークペアの結果がシート別（`fcc200`, `fcc111bcc110` 等）に自動出力されます。
  * 2ピーク強度比探索モードの最適化履歴グラフ（`R value vs Total Residual`）や各ピークの推移グラフ画像も `openpyxl.drawing.image.Image` を用いてExcelシート内へ自動添付されます。ファイルがExcelで開かれていて書き込みロックされている場合も、日時付きフォールバック名で安全に保存します。
